# Koda VK roadmap

## Shipped

- 1.0.0: native VK session, recommendations, search, library, favorites and playlists.
- 1.0.0: playback through Koda's Media3 queue and all Koda music-player styles.
- 1.0.0: VK-only application entry point, independent package id and update repository.

## Next

- Native artist and album endpoints when VK exposes stable response shapes for them.
- VK lyrics endpoint integration.
- Android Auto browse tree backed by VK instead of the transitional legacy tree.
- More languages for the new VK-specific surfaces.
